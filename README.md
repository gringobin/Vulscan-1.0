# 🔥 Vulscan

**Vulscan** es una herramienta avanzada de reconocimiento y análisis de vulnerabilidades escrita en Python.  
Combina escaneo de puertos, detección de servicios, reconocimiento de versiones y búsqueda automática de CVEs mediante OSINT.

Su objetivo es simplificar la fase de enumeración y brindar resultados accionables en un solo comando.

—

## 🚀 Características principales

- 🔍 **Escaneo completo de puertos**
- 🛠️ **Detección de servicios y versiones (banner grabbing)**
- 🧩 **Búsqueda automática de vulnerabilidades (CVE lookup)**
- 🌐 **Integración OSINT**
- 📑 **Reporte estructurado con detalles críticos**
